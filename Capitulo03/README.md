# Laboratorio 3: Incorporar factores externos mediante el agente Investigador

**Duración:** 14 min

## Descripción
Los participantes utilizarán Investigador (Researcher) para analizar un sector real que servirá como referencia pública para la operación ficticia. Solicitarán identificar tendencias, acontecimientos y factores económicos, sectoriales o regulatorios relevantes para el análisis, conservando fuentes y fechas y diferenciando hechos documentados de interpretaciones. El resultado deberá enfocarse en aportar evidencia para la evaluación, sin emitir por sí mismo una clasificación final del riesgo.

## Pasos para ejecutar la práctica

1. **Selección del agente especializado:**
   * En la interfaz de Microsoft 365 Copilot, selecciona y activa el agente **Investigador (Researcher)**.

2. **Ejecución del plan e investigación del entorno sectorial:**
   * Copia, pega y envía el siguiente prompt estructurado:
     ```text
     Escribe primero un PLAN DE INVESTIGACIÓN de 3 pasos para analizar el sector de energía e infraestructura en la región (últimos 12 meses):
     1. Tendencias del mercado y desempeño financiero general.
     2. Cambios regulatorios y macrotendencias de sostenibilidad.
     3. Factores de riesgo económico y tasas de interés.

     A continuación, ejecuta el plan realizando una búsqueda rápida y entrega un informe síntesis en viñetas cortas que conserve fuentes clave y fechas explícitas, separando datos objetivos de interpretaciones, sin emitiir una clasificación final del riesgo.
     ```

3. **Exportación del informe sectorial a Word:**
   * Al finalizar la respuesta de Copilot, selecciona **Exportar a Word** y guarda el archivo con el nombre exacto: `Informe_Investigacion_Sectorial.docx`.

## Resultado esperado
Un documento guardado como `Informe_Investigacion_Sectorial.docx` que reúne los hallazgos de mercado y factores externos procesados por el agente Investigador.
