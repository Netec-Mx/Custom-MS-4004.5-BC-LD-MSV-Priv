# Laboratorio 1: Diseñar una estrategia para el análisis de alta volumetría

**Duración:** 9 min

## Descripción
Los participantes conocerán la composición del expediente ficticio de alta volumetría y utilizarán Copilot para diseñar una estrategia de análisis. Determinarán cómo segmentar las fuentes en bloques manejables, qué preguntas realizar sobre cada grupo, qué resultados conservar y cómo consolidarlos posteriormente. La estrategia deberá preservar la relación entre fuente, hallazgo y regla de negocio aplicable, además de contemplar mecanismos para identificar información pendiente de analizar.

## Pasos para ejecutar la práctica

1. **Definición de la composición del expediente financiero:**
   * Abre Microsoft 365 Copilot Chat.
   * Copia, pega y envía el siguiente prompt para estructurar el inventario del expediente:
     ```text
     Actúa como un Especialista en Gestión de Riesgo Crediticio y Financiero.
     
     Crea un inventario estructurado para un expediente corporativo de alta volumetría compuesto por 4 bloques documentales:
     - Bloque A: Reglas de Negocio y Políticas de Riesgo.
     - Bloque B: Estados Financieros e Indicadores Cuantitativos.
     - Bloque C: Informes Sectoriales y Entorno Macroeconómico.
     - Bloque D: Antecedentes Cualitativos y Garantías de la Operación.
     ```

2. **Diseño de la estrategia de análisis y segmentación:**
   * En el mismo chat, envía el siguiente prompt para establecer la estrategia de procesamiento progresivo:
     ```text
     Diseña una Estrategia de Análisis Progresivo para abordar los 4 bloques documentales sin perder trazabilidad.
     
     Para cada bloque define:
     1. Objetivo específico de análisis.
     2. Preguntas analíticas clave.
     3. Regla de conservación de evidencia (Relación: Fuente -> Hallazgo -> Criterio).
     4. Criterios para marcar información pendiente de validación.
     ```

3. **Exportación de la estrategia a documento Word:**
   * Haz clic en el botón de opciones o selecciona **Exportar a Word** y guarda el archivo generado con el nombre exacto: `Estrategia_Analisis_Expediente.docx`.

## Resultado esperado
Un documento guardado como `Estrategia_Analisis_Expediente.docx` que contiene el marco formal de segmentación y procesamiento progresivo para el expediente financiero de alta volumetría.
